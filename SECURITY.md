# Security Policy

## Supported Versions

Security fixes are provided for the latest released version of this project.
Older versions may be unsupported unless a maintainer explicitly says otherwise
in a release note or security advisory.

## Reporting a Vulnerability

Please report suspected security vulnerabilities through GitHub private
vulnerability reporting for this repository.

Do not open a public issue or pull request for a suspected vulnerability before
maintainers have reviewed it. Include enough detail to reproduce the issue when
possible:

- The affected version or commit.
- The steps required to reproduce the behavior.
- The expected and actual security impact.
- Any relevant environment details.

Maintainers will review private reports, coordinate fixes, and publish a
security advisory when public disclosure is appropriate.
